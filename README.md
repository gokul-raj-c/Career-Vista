# 🎓 CareerVista – AI-Powered Career Guidance System

**CareerVista** is an intelligent machine-learning–based career guidance platform designed to help students make informed academic and career decisions.  
It analyzes interests, skills, academic performance, and personality traits to deliver highly accurate and personalized recommendations.

CareerVista uses **four dedicated ML modules** for:  
✅ Stream Prediction  
✅ Career Path Prediction  
✅ Academic Recommendations  
✅ Job Role Prediction  

## 🎯 Objective

CareerVista aims to:

- Analyze student data to understand strengths and interests  
- Predict the most suitable **academic stream**  
- Recommend personalised **career paths**  
- Evaluate **academic performance %** and improvement needs  
- Predict ideal **job roles** for long-term planning  
- Provide interpretable, data-driven insights  


## 🧩 System Modules

### **1️⃣ Stream Prediction Module**
Predicts the best academic stream for a student, such as:
- Science  
- Commerce  
- Arts  

Based on:
- Academic scores  
- Skill levels  
- Interest patterns  

### **2️⃣ Career Path Prediction Module**
Recommends broad career fields, such as:
- Engineering  
- Medicine  
- IT & Software  
- Business & Management  
- Finance  
- Creative Arts  
- Media & Communication  


### **3️⃣ Academic Recommendation Module**

Provides:
- **Academic performance % evaluation** to assess academic standing and readiness for future goals  


### **4️⃣ Job Role Prediction Module**
Predicts specific job profiles such as:
- Data Scientist  
- Software Engineer  
- Accountant  
- Graphic Designer  
- Psychologist  
- Mechanical Engineer  
- Digital Marketer  
*(and more depending on dataset)*

## 🤖 Algorithms Used

CareerVista uses optimized machine learning algorithms for each prediction module.  
Based on performance and dataset behavior:


### **1️⃣ Stream Prediction Module**
Predicts the suitable academic stream (Science, Commerce, Arts).

**Algorithm Used:**
- **Random Forest Classifier**


### **2️⃣ Career Path Prediction Module**
Recommends a suitable future career domain.

**Algorithm Used:**
- **Random Forest Classifier**


### **3️⃣ Academic Recommendation Module**
Predicts academic performance %.

**Algorithm Used:**
- **Linear Regression** (for Academic Performance % prediction)  


### **4️⃣ Job Role Prediction Module**
Predicts the most suitable job role for the student.

**Algorithm Used:**
- **Random Forest Classifier**
